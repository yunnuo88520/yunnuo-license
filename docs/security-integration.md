# 授权拦截、证据与申诉（V2）

授权站在在线验证与更新接口执行策略，产品负责在受保护的页面、API 或关键功能执行验证结果。客户端上报只是待核实证据，不会自动被认定为盗版或封禁。

## 页面配置与处置

1. 打开“应用授权中心 → 应用与策略 → 拦截公告”，设置是否显示公告、纯文字内容及可选 HTTP(S) 联系链接。例如“站点未授权，联系QQ531023977”。保存后可预览，电脑、手机、浅色和深色共用同一模板。公告最多 3000 字节，HTML 会被转义。
2. 在“审计与诊断”查看 `integrity_reported`、验证失败原因及客户 `security_appeal` 事件，核对购买记录、安装、版本与证据摘要。签名只能证明持有安装私钥，不能证明客户报告真实。
3. 在许可证行选择“安全处置”，填写人工核实原因，可只限制更新、解除更新限制或仅记录观察。只限制更新时产品仍可使用，检查、下载和安装更新均拒绝；已有期限不会因此延长。
4. 需要停用产品时，另用“状态”暂停或永久吊销许可证。暂停可恢复，吊销不可恢复。恢复状态仍需通过期限、绑定、席位和其他正常检查。
5. 客户在用户中心选择自己的授权提交申诉，获得事件回执。管理员或所属开发者核实后执行恢复，并在操作原因中记录申诉回执。所有事件追加保存，客户不能自行解除限制，历史证据不会被覆盖。

关闭公告只改变产品提示的显示配置，不会恢复吊销许可证或授予更新权益。平台操作日志提供平台操作的分类查询；应用证据与处置在各应用审计中隔离。

## 接入真实产品

在接入页选择 Python 并下载项目，按随包配置设置绑定和私有状态目录：

```bash
python -m pip install -r requirements.txt
# 设置授权站地址、绑定、产品私有管理员密码和持久目录后运行：
python web.py --bind 127.0.0.1 --port 8088
```

`web.py` 为可运行的 B/S 示例。客户通过其 `/activate` 页面使用产品自己的 Basic 管理账号输入购买的卡密，账号默认 `owner`，密码由 `YN_PRODUCT_ADMIN_PASSWORD` 设置；这不是授权站 AppSecret。未设置密码时禁用网页激活，仍可用命令行。生产应由 HTTPS 反向代理保护该私有入口。

网站受保护的页面与 API 在输出业务内容前调用 `client.py verify`。无法获得有效授权时返回 HTTP 403，并加载授权站 `/v2/applications/{app_id}/block-page` 的固定安全模板及公告。关闭公告后显示普通授权不可用提示。域名绑定取实际 Host，不能信任任意转发头；反向代理应保留配置的真实站点 Host。其他语言按同一验证结果接入自己的路由或业务服务，不强制使用 Python。

安装凭证和 JWT 放入客户独立持久目录；发布包中只含公开 AppID、公钥及通用程序。产品必须处理验证返回的 `valid`，不能只以“请求未抛异常”作为授权通过。网络故障仅按签名离线策略回退；收到暂停、吊销、过期、绑定或签名错误的明确响应后清除 JWT，不得离线放行。更新始终在线核验。

Python 示例还可签名上报证据：

```bash
# 填写实际待核实文件的 SHA-256，不上传文件、卡密或硬件原文：
export YN_EVIDENCE_SHA256=<64位SHA256>
export YN_INTEGRITY_SUMMARY='文件与预期发行版本不同，请人工核对'
python client.py report
```

运行接口为 `POST /v2/security/report`，请求包含 `app_id`、`activation_id`、`signal`、`evidence_sha256`、`summary`，采用与 activate/verify 相同的独立安装请求签名、时间窗口和 nonce 检查。信号可选 `binary_modified`、`unexpected_signature`、`copied_installation`。只知道安装 ID 不能提交报告，跨应用证据不能被当前处置引用。成功返回 `event_id` 和 `status=pending`。

## 能力边界

授权站不能让已离线的 JWT 即时失效，也无法阻止攻击者删除客户端验签和拦截代码。缩短 TTL、关闭或缩短离线容忍可减少响应窗口，收费动作和敏感业务放到可信服务端可以进一步约束风险。公告、签名证据和人工处置不能替代代码保护、软件完整性机制或购买凭证核实。

真实页面、签名上报、只禁更新、客户申诉与恢复验收见 `examples/platform-e2e/test_authorization_v2.py`；实际网站到期拦截、更新验签、客户数据迁移和回滚验收见 `examples/update-demo/test_v2.py`。
