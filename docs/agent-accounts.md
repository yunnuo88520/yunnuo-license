# 用户与代理账号

用户中心与代理工作台使用同一个普通用户账号、个人邮箱和密码。代理是用户获得的经营资格；代理资料、采购等级、可售套餐、钱包和历史流水归所属经营主体，便于审计和可选团队协作。管理员和开发者控制台继续单独校验其管理身份与应用范围。

## 管理员开通

1. 在“套餐与结算”建立应用套餐，按需建立代理等级和等级成本价。等级不会自动增加可售应用。
2. 在“代理”点击“开通代理账号”，选择创建新用户或绑定已有用户。绑定已有用户沿用原密码和个人邮箱，不改其已购买的授权；也可从“用户”列表点击“开通代理”。
3. 同一弹窗填写代理显示名称、等级、可售套餐或应用分组、单批上限、导出权限，以及可选初始余额。分组只授予当前已上架的套餐，后续新套餐需要另行授权。
4. 保存后可用用户账号或绑定邮箱和密码进入 `/agent-console/`，无需代理代码。用户中心入口为 `/user-console/`，同一标签页切换不需要重新登录。

保存过程在一个数据库事务内创建或关联用户、代理资格、成员、等级、钱包、套餐权限、初始余额流水和审计。配置无效或审计失败全部回滚。重复为同一用户开通返回冲突，不产生额外代理或充值。零余额可登录，有成本的套餐需要余额足够才能发卡。

选择代理“详情”，在同一页面管理等级、套餐、专属成本、余额及资金流水，无需单独建立产品发卡规则。金额以人民币分记账，套餐报价由服务端决定；扣款、生成卡密、成本流水和审计原子提交，请求 ID 防止重复发卡或扣款。张数额度为可选附加限制，默认余额结算无需另行发放。

## 资格、账号与授权状态

| 操作 | 代理业务 | 用户中心 | 已有授权 |
| --- | --- | --- | --- |
| 暂停或停用代理资格 | 立即禁止访问和新发卡 | 用户账号有效时可用 | 不自动改变个人或已售客户授权 |
| 停用团队成员 | 该成员不能进入代理工作台 | 用户账号有效时可用 | 不改变授权归属或期限 |
| 停用用户账号 | 该账号两端访问均停止，旧会话撤销 | 禁止登录 | 不直接吊销应用授权，吊销需单独操作 |
| 修改或恢复个人密码 | 两端旧会话同时失效 | 两端使用同一新密码 | 不改变授权归属、期限或绑定 |

用户只能查看自己持有的授权；代理只能管理所属经营主体的发卡、钱包与流水。代理可售应用范围与个人持有授权独立校验。代理暂停不会让已售出的正版客户失去授权。使用与更新资格继续由应用规则、授权状态、独立期限及已确认安全处置决定；更新到期不能获取升级包。

密码找回只使用用户自己的账号邮箱。业务联系邮箱用于通知，不能接管团队成员的统一账号。通过任一恢复入口重置密码都会撤销两端旧会话。

## 可选团队与迁移

个人代理无需添加账号。在代理详情展开“团队协作”可由管理员创建成员；成员各有独立用户身份及负责人、经理、员工或只读权限，共享代理的钱包与可售范围。当前一个用户仅归属一个代理经营主体。价格等级与成员操作角色分别设置，上下级代理和分佣不是成员管理。

启动迁移将旧代理成员关联到独立普通用户，保留密码与业务记录。同名账号不会自动合并身份，而使用 `agent-<原成员 ID 后缀>`；后台代理列表显示实际登录名。重复启动不会新建重复用户。原代理会话仍按业务状态校验，改密会一并撤销；旧客户端可提交原代理定位字段，新的登录页不需要。

接口：`POST /admin/agent-accounts` 一次开通，`GET /admin/agent-accounts/eligible-users` 返回未具代理资格的有效用户，仅平台管理员可调用。已有用户传 `user_id`，新用户传 `username`、`password` 及可选 `display_name`、`email`，两种方式不能混用。其余配置字段见页面或 `OpenAgentInput`。不要将密码、令牌、完整卡密写入截图或日志。

复跑方式见 [平台验收](../examples/platform-e2e/README.md)。
