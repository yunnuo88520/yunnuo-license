# 商业运营信息模板

上线时由运营方填写下列信息，并在实际站点提供对应入口；本文件不自动发布或代替双方合同。

| 项目 | 需要明确的内容 |
| --- | --- |
| 服务主体 | 公司/经营者名称、服务联系方式、支持时间、故障反馈渠道 |
| 产品权益 | 订阅或永久使用、更新期限、宽限期、可绑定方式和数量、换绑次数/冷却、授权归属转移规则 |
| 服务边界 | 授权站的可用性目标、产品方必须接入校验/更新验签、客户端破解的处置与申诉流程 |
| 代理结算 | 预付余额确认方式、套餐价格与等级比例、生效时间、扣款争议、停用资格不影响已售授权 |
| 收款与退款 | 首期人工确认入账的凭证与核对流程、退款条件、到账和对账周期；在线支付上线后另补商户规则 |
| 数据与隐私 | 账号邮箱、授权绑定标识、IP 与操作日志的用途和保留期、访问权限、备份位置、删除或更正申请渠道 |
| 盗版处置 | 检测证据、人工复核、限制更新/限制使用/拦截公告的适用规则、用户申诉及恢复机制 |
| 运维与交付 | 备份频率与恢复演练、故障沟通、版本维护和停止服务后的授权处理约定 |

域名、IP、账号等绑定标识按用途最少收集。不要在公告、公开查询或告警标签中发布用户的完整邮箱、卡密、令牌或应用密钥。
